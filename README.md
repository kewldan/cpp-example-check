# C++ Example Checker

Плагин для **Visual Studio Code**: одной кнопкой проверяет решение на C++
на примере из условия.

**Автор:** Тенишев Даниил Александрович, группа M3105

## Возможности

- Пример из условия пишется в файл решения, в комментарий.
- Над комментарием появляется кнопка **▶ Проверить пример**.
- По нажатию решение компилируется (`g++ -std=c++20 -O2`) и запускается на
  примере с ограничением в 2 секунды, а на месте кнопки пишется
  **✅ Сошлось** или **❌ Неверное решение**. При ошибке компиляции —
  **⚠️ Ошибка**, текст ошибки в панели Output.
- Пробелы и переводы строк в ответе не важны.

## Как пользоваться

```cpp
/*
input:
5
1 -2 3 4 -1
output:
7
*/
```

Короткий пример можно записать в одну строку:
`/* input: 3 2 2 2 output: 6 */`. Готовый пример — в
[`examples/A.cpp`](examples/A.cpp).

## Сборка

```bash
bun install
bun run compile
```

`bun run lint` проверяет стиль через [Biome](https://biomejs.dev),
`bun run package` собирает `.vsix`. В VS Code `F5` запускает окно с плагином.

Устройство плагина описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
