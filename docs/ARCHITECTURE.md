# Архитектура C++ Example Checker

## Техническое задание

- IDE: Visual Studio Code, язык плагина: TypeScript.
- Пример записывается в файл `.cpp` комментарием `/* input: … output: … */`.
- Над каждым примером — кнопка **▶ Проверить пример**.
- По нажатию решение компилируется, запускается на входе примера с
  ограничением времени, и вывод сравнивается с ответом.
- Результат показывается на месте кнопки: «✅ Сошлось» или «❌ Неверное решение».
  Ошибка компиляции выводится в панель Output.

## Как VS Code подключает плагин

Расширение — это модуль Node.js, который работает в отдельном процессе
Extension Host и общается с редактором через API `vscode`.

1. `package.json` объявляет команду и событие активации `onLanguage:cpp`.
2. При открытии файла C++ VS Code вызывает `activate()` из
   `out/extension.js`.
3. `activate()` регистрирует CodeLens-провайдер (он отдаёт кнопки над
   строками) и команду, которую вызывает кнопка.

## Модули

| Модуль         | Что делает                                                    |
| -------------- | ------------------------------------------------------------- |
| `extension.ts` | Кнопки над примерами, их статусы и обработчик нажатия         |
| `tests.ts`     | Находит примеры в комментариях                                |
| `judge.ts`     | Компилирует, запускает на примере (до 2 с), сравнивает ответ  |

## Структуры данных

- Примеры ищутся двумя регулярными выражениями: первое находит блочные
  комментарии, второе делит комментарий на `input` и `output`.
- Статусы кнопок хранятся в словаре `Map`: файл → (номер примера → статус).
  При правке файла его статусы удаляются.
- Ответы сравниваются как массивы слов.
